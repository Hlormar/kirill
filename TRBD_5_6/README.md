## Запуск

Откройте `Готовая_программа/WindowsFormsApp1.exe`. Все DLL и подпапки рядом с EXE должны оставаться на месте. Программа рассчитана на Windows с .NET Framework 4.7.2 или новее; установленный на этом компьютере .NET Framework подходит. Microsoft Office для формирования файлов не нужен.

В архиве папка готовой программы называется `Программа`. Сначала распакуйте весь архив, затем запускайте EXE.

Локальная база — `Data/store.sqlite` рядом с EXE. В готовой программе уже есть демонстрационные данные за сентябрь 2026 года. Если базы нет, при запуске она создаётся автоматически из `Database/schema.sql` и `Database/seed.sql`. Для резервной копии закройте программу и скопируйте файл базы.

## Работа

Окна оформлены в едином светлом стиле. Редакторы открываются по размеру полей и состава документа. При изменении размеров поля растягиваются по ширине, таблицы занимают доступное место, а элементы панели отчётов переносятся на следующую строку. В небольшом редакторе справочника появляется прокрутка. Если таблица содержит много столбцов, горизонтальная прокрутка сохраняет читаемую ширину колонок.

- Меню **Справочники**: категории, должности, поставщики, товары и сотрудники.
- Меню **Документы**: поставки, продажи, возвраты и списания. Верхняя таблица содержит документы, нижняя — позиции выбранного документа.
- На панели списка доступны добавление, редактирование, удаление, поиск, обновление и закрытие. Поиск выполняется по полю, указанному рядом с текстовым полем, без учёта регистра, включая кириллицу.
- В редакторе документа заполните реквизиты и состав. Для новой позиции используйте последнюю строку. Delete удаляет выбранную строку состава. Один товар указывается один раз; количество может быть дробным.
- Поставка увеличивает остаток; продажа и списание уменьшают; возврат увеличивает. Операции, приводящие к отрицательному остатку, отменяются целиком.
- Возврат привязан к продаже: товар должен входить в исходный чек, суммарный возврат не может превышать проданное количество. Сумма рассчитывается по цене из чека. Изменение цены товара не пересчитывает старые документы.
- Маска карты вводится в формате `**** 1234`. Срок годности в составе поставки — `yyyy-MM-dd`, поле можно оставить пустым.
- Запись, используемая в других документах, защищена от удаления. Удаление документа и его состава выполняется в одной транзакции.
- Открытые списки можно актуализировать кнопкой **Обновить** после изменения данных в другом окне.

## Экспорт

Меню **Отчёты**:

- Продажи — Word `.docx`: продажи за период, сотрудники, товары, категории, возвраты и сумма после возвратов.
- Поставки — Excel `.xlsx`: поставщики, товары, категории, количества, цены и стоимость; числовые ячейки остаются числами, включены фильтр и закрепление заголовка.
- Остатки и сроки годности — PDF: текущие остатки и стоимость по розничным ценам.
- Доход за всё время — продажи минус возвраты минус закупки, по формуле отчёта 3–4.

Для примеров выберите период, включающий сентябрь 2026 года. В окне отчёта нажмите **Сформировать**, затем **Сохранить файл**. Запросы и запись файлов выполняются в фоновых потоках, интерфейс получает результаты после завершения работы.

Схема не связывает расход с конкретной партией: срок годности в PDF — ближайшая дата среди поставок товара, справочная информация, а не расчёт остатков по партиям. У возврата в исходной модели нет даты, поэтому в Word возвраты учитываются за всё время по продажам выбранного периода.

## Проект

Откройте `WindowsFormsApp1.sln` или существующий `WindowsFormsApp1.slnx` в Visual Studio с компонентом «Разработка классических приложений .NET» и targeting pack .NET Framework 4.7.2. Восстановите NuGet-пакеты и соберите проект. Зависимости закреплены: System.Data.SQLite.Core 1.0.119 и PDFsharp 1.50.5147. При первой сборке нужен доступ к NuGet.

Физическая модель со страницы 22 отчёта 3–4 используется как основа. Связь списания с сотрудником сохранена из SQL-скрипта; суммы позиций продаж и возвратов хранятся в базе. Связь товара со справочником категории реализована через CategoryID; позиции документов ссылаются на ProductID. Всего 13 таблиц и представление Stock.

Основные файлы: `Catalog.cs` — метаданные; `Database.cs` — ADO.NET, запросы и транзакции; `Form1.cs` — MDI и меню; `DataForm.cs` — списки и состав; `EditForm.cs` — редакторы; `Reports.cs` — запросы и экспорт; `Verification.cs` — проверка на изолированной базе.

## Проверка

В исходной рабочей папке выполните `powershell -NoProfile -ExecutionPolicy Bypass -File Verify.ps1`. Скрипт собирает Release и запускает проверку базы, транзакций, поиска, возвратов, экспортов и скрытых окон. Результат — `verification/verification.txt`. Программа также поддерживает `WindowsFormsApp1.exe --verify "папка_результатов"`. Проверочная база создаётся отдельно; пользовательская база не меняется.

Поставленная Release-сборка прошла эти проверки. Учебный письменный отчёт по просьбе пользователя не создавался.
